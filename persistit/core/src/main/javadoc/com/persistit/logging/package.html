Implements Persistit™'s logging mechanism and provides a simple method for connecting Persistit's log output to the embedding application. The default logger writes log messages to the file persistit.log and overwrites that file each time Persistit is initialized.

To override the default logger, for example, to route Persistit's log messages to the embedding application's logging subsystem, implement a subclass of {@link com.persistit.logging.DefaultPersistitLogger DefaulttPersistitLogger} and install it with the static {@link com.persistit.Persistit#setPersistitLogger setPersistitLogger} method of Persistit.

Also see the {@code JDK14LoggingAdapter}, {@code Log4JAdapter} and {@code ApacheCommonsLogAdapter} classes, which wrap a JDK 1.4 java.util.logging.Logger, org.apache.log4j.Logger, and org.apache.commons.logging.Log, respectively.
